Microsoft Entra ID single sign-on for a legacy platform In progress

Moving an established ASP.NET WebForms login to Microsoft sign-in, without locking anyone out.

Challenge
Existing users on a custom login, plus new .NET 10 services that need the same identity.
Approach
A phased rollout: OWIN middleware on WebForms, Entra app registrations, users matched by their immutable Entra object ID, and a dual-auth .NET 10 API that accepts both Entra tokens and legacy JWTs.
Why
Old and new logins work side by side, so each phase ships on its own and nobody is forced through a big-bang cut-over.
  • Microsoft Entra ID
  • OAuth / OpenID Connect
  • OWIN
  • JWT
  • .NET 10
  • ASP.NET WebForms

Teachers Portal

One dashboard for feeds, mail, timetable and calendar.

Challenge
Built for large-scale concurrent use at the same times of day.
Approach
Standalone Blazor WebAssembly with a separate .NET 10 Web API, JWT auth and a custom AuthenticationStateProvider, deployed on IIS.
Why
Blazor Server holds a live SignalR circuit per user. Running the UI in the browser keeps server load flat at peak.

  • ASP.NET Core Web API
  • .NET 10
  • Syncfusion
  • IIS

Approach

SQL Server schema audit and repair

Core teacher and student-set tables, hardened.

Challenge
Tables had grown without enforced relationships or matching data types.
Approach
Audited the schema and shipped a corrected script: foreign keys, indexes on FK columns, uniqueness and optimistic-concurrency controls, and fixed type mismatches.
Why
The database rejects bad data itself, and joins on foreign keys stay indexed.
  • SQL Server
  • Data integrity
  • Performance
